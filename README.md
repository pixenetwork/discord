# Pixel Network Discord Workers

Dedicated Discord worker repository for Pixel Network projects.

The first production surface is **Aquaphoria Discord**: customer support, breeder/vendor catalogs, order fulfillment tickets, Aquapedia research commands, audit logging, and storefront integrations.

Discord-specific runtime code belongs here. Jarvis (`ai-orchestrator`) remains the orchestration/AI control plane, while Aquapedia remains the evidence-backed research knowledge base.

> No credentials belong in this repository. Runtime secrets are provided through environment variables.
