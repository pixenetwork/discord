**Source limitations:** A historical taxonomic description supports the named work and original placement, not the identity of a hobbyist's fish. The `pseudo-sidereus` forum carries a generic-placement dispute, so any later combination/revision remains a separate source-review question; the index explicitly points only to the original description. The `hyp-contradens` thread notes that L201a is not an official scientific name; no trade equivalence is asserted. Publication years and nomenclature must be read from the primary papers, not automatically derived from the forum title.

The change in combination needs its own qualified, source-linked taxonomic history.

This reference can provide comparative context but is **not** a direct original description of *P. changae*.
